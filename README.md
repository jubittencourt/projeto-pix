#  Projeto Pix

Sistema desenvolvido como projeto acadêmico para simular operações básicas de um sistema de pagamentos via **Pix**.

O projeto foi desenvolvido em equipe, com o objetivo de aplicar na prática conceitos de desenvolvimento **Back-End**, organização de código, APIs REST, persistência de dados e integração com banco de dados.

---

## 📌 Sobre o projeto

O **Projeto Pix** consiste em uma aplicação Back-End desenvolvida com **Java e Spring Boot**, responsável pelo gerenciamento de usuários, pessoas e transações.

A aplicação utiliza uma arquitetura organizada em diferentes camadas, buscando separar as responsabilidades e facilitar a manutenção e evolução do sistema.

### Funcionalidades

* 👤 Cadastro e gerenciamento de usuários
* 🧑‍💼 Gerenciamento de pessoas
* 💸 Criação e gerenciamento de transações
* 🗄️ Persistência de dados
* 🔗 Comunicação entre as diferentes camadas da aplicação
* 🌐 Estrutura preparada para operações através de API REST

## 🏗️ Estrutura do projeto

O projeto está organizado seguindo uma divisão por responsabilidades:

```text
src/
└── main/
    └── java/
        └── projetofaculdade/
            └── com/
                └── pix/
                    ├── config/
                    ├── controle/
                    ├── model/
                    ├── repository/
                    ├── servico/
                    └── PixApplication.java
```

### 📂 Principais camadas

**`model`**
Contém as classes responsáveis pela representação das entidades utilizadas pelo sistema.

**`repository`**
Responsável pela comunicação e persistência dos dados utilizando Spring Data JPA.

**`servico`**
Concentra as regras e operações relacionadas à lógica da aplicação.

**`controle`**
Responsável pelos controllers e pela comunicação com as requisições da aplicação.

**`config`**
Contém configurações utilizadas pela aplicação.
